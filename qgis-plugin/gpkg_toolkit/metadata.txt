description=A GeoPackage data provider, and tools to validate, repair and inspect GeoPackages, sample elevation coverages and export layers, using the Rust geopackage crate.
about=A vector data provider (geopackage_rs) that reads and edits GeoPackage layers through the geopackage Rust crate rather than OGR, with SQL subset strings, RTree bounding-box reads and column projection; and Processing algorithms built on the same crate: a validator that reports what is wrong with a GeoPackage and how to repair it; spatial index audits and repairs, including legacy pre-1.4 triggers; repairs of non-standard geometry and DATETIME encodings; the extension catalogue with this crate's support for each row; value lookups, per-tile statistics and Requirement 21 checks on tiled gridded coverages; and a bulk layer export. The plugin contains compiled code, built from its source repository: the geopackage_rs Python module for Linux (x86_64 and aarch64, glibc 2.28 or later), macOS (arm64 and x86_64) and Windows (x86_64), and a native build of the data provider for QGIS 4.0 and 4.2 on each. Where there is no native build for the running QGIS, including on QGIS 3, the provider runs in Python. It needs nothing else installed.
