description=A GeoPackage data provider, and Processing algorithms that validate, repair and inspect GeoPackages, read values from elevation coverages and export layers. Built on the geopackage Rust library.
about=The data provider, geopackage_rs, reads and edits GeoPackage layers through the geopackage Rust library instead of GDAL. It supports subset strings (SQL filters), spatial index queries, and reads only the columns a request needs. The Processing algorithms use the same library. They find the problems in a GeoPackage and name the algorithm that repairs each one; check and repair spatial indexes, including the triggers of GeoPackage versions before 1.4; repair geometries and datetimes that are not in the standard form; list the file's extensions and which of them the plugin supports; read the values of a coverage, such as an elevation model, at points; calculate statistics for each coverage tile; find NaN and infinite values in coverages; and export a vector layer to a GeoPackage. The plugin contains compiled code, built from its source repository: the geopackage_rs Python module for Linux (x86_64 and aarch64, glibc 2.28 or later), macOS (arm64 and x86_64) and Windows (x86_64), and a native build of the data provider for QGIS 4.0 and 4.2 on each. On a QGIS version with no native build, including QGIS 3, the data provider runs in Python. The plugin needs no other software.
